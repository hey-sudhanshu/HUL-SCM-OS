# Decisions Log

This document tracks technical and design decisions made throughout the development of HUL SCM OS.

## Initial Setup
- **2026-09-20**: Initialized project planning artifacts based on `PROJECT_SPEC.md`. Project will follow a simple modular structure (`apps/web` and `apps/solver`) rather than a complex monorepo configuration initially, prioritizing speed of setup unless specified otherwise.
- **2026-09-20**: Based on user feedback, the visual direction overrides the original "Paper OS" monochrome design in Section 4. We are strictly adhering to the classic Mac OS 7.5 reference design (gradient wallpaper, CRT scanlines, classic Apple-like menu bar, sticky notes, and Dogcow).
